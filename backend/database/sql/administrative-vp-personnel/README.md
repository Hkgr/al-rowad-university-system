# صلاحيات إدارة المدرسين والعمداء

بعد أخذ نسخة احتياطية، نفّذ `00_preflight.sql` للقراءة فقط وتحقق من `READY` لكل نتيجة، ثم `01_apply.sql` وتحقق من `APPLIED`، ثم `02_verify.sql` وتحقق من `PASS` لكل نتيجة. الملفات تشير صراحةً إلى قاعدة `alrowad_uni_rust`، ولا تنشئ أي حساب تجريبي. أعِد تطبيق `01_apply.sql` بأمان. للتراجع عن صفوف الصلاحيات التي أنشأتها الحزمة فقط استعمل `03_rollback.sql`؛ يتوقف عند وجود رابط مع دور آخر أو كائن غير موسوم بالملكية. لا يحذف التراجع بيانات الموظفين أو الحسابات المنشأة من واجهة التطبيق.
